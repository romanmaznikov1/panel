# Демо-стенд панели учёта для студии «Пляски»

Панель учёта учеников, посещаемости, абонементов, зарплат и финансов в
фирменном стиле «Плясок» (Екатеринбург: Ирбитская 13, Уральская 5,
Космонавтов 9А). Внутри — выдуманная, но правдоподобная история работы студии
за последние полгода. База — файл `data/plyaski.sqlite3`, он собирается
скриптом и в репозиторий не попадает.

## Railway

Проект готов к деплою как есть: New Project → Deploy from GitHub repo →
этот репозиторий. Railway сам возьмёт `railway.json`:

- при каждом запуске `demo/start.sh` собирает свежие демо-данные на сегодня;
- каждую ночь в 04:00 (Екатеринбург) данные пересобираются заново — всё, что
  нажали на показе, стирается;
- панель слушает порт, который выдал Railway.

После деплоя: Settings → Networking → **Generate Domain** — это и есть ссылка
для показа. Переменные окружения задавать не нужно.

Каждую ночь база создаётся заново, поэтому утром в панель нужно войти ещё раз.

## Запуск на своём компьютере

Из корня репозитория:

```
python3 app/server.py
```

Откроется `http://127.0.0.1:8777/`.

Входа нет (демо-режим включён по умолчанию, `DEMO=0` его выключает): ссылка сразу
открывает панель под владелицей. Внизу бокового меню (на телефоне — «Ещё»)
кнопка «Вид администратора» показывает, что видит администратор: без
финансов и зарплат. Пароли и доступы в демо менять нельзя.

С `DEMO=0` вход обычный:

| Кто | Логин | Пароль |
|---|---|---|
| Владелица | `dilyara` | `plyaski2026` |
| Администратор | `admin` | `admin2026` |

## Перед показом — обновить историю

```
python3 demo/generate_demo.py
```

Скрипт пересоздаёт базу с нуля так, что всё отмечено по вчерашний день, а
сегодняшние занятия ещё пустые: их можно отметить прямо на встрече.
Все изменения, сделанные в демо, при этом стираются.

## Что в данных

- **Детские группы** (3–14 лет): детский, эстрадный, современный и классический
  танец, ритмика, базовая акробатика, ОФП. Педагоги с сайта: Жимердей
  Александра, Шипкова Юлия, Заболотных Кристина, Клюсова Дарья.
- **Взрослые группы** (только Ирбитская и Уральская): женские танцы, здоровая
  спина, силовая, пилатес, растяжка, кардио.
- **Абонементы:** детские 4/8/12 занятий за 3 900/5 900/6 900 ₽ (цены с сайта),
  бесплатное пробное для детей, первое занятие за 490 ₽ для взрослых (с сайта).
- **Сезонность:** весной группы полные, летом спад (дачи, лагеря), в сентябре
  набор: много пробных, и большинство после них покупает абонемент.
- Продления и уходы, разовые визиты взрослых, индивидуальные занятия (подготовка
  к конкурсам), скидка 10% на второго ребёнка, премии за отчётный концерт.

**Придумано, а не взято с сайта:** все ученики и телефоны, цены взрослых
абонементов (2 900/4 600/5 900 ₽), разовое занятие (800 ₽), индивидуальное
(2 000 ₽), ставки педагогов, взрослые тренеры (Сафина Гульнара, Ковалёва
Анастасия), администраторы (Мингазова Алина, Лаптева Софья), аренда и прочие
расходы.
